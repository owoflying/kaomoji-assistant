# 颜文字输入辅助器 (Kaomoji Assistant)

> 本项目由 AI 辅助生成。

Win11 风格的颜文字输入辅助工具。按全局热键唤起候选面板，搜索并选择颜文字，回车即输入到当前光标位置。

## 功能

- 全局热键唤起（默认 `Ctrl+Shift+K`）
- Win11 风格面板：半透明、圆角、亚克力模糊、浅/深双主题
- 实时搜索、`1`–`9` 直接选字、最近使用与收藏夹
- **候选按你的使用习惯排序**（频率 + 新近度 + 收藏，最常用的稳定在首位）
- **情绪识别**：打出「好累」「破防了」这类词自动推荐对应表情，
  由一个约 4500 参数的小神经网络判断，能听懂否定句与转折句
- 失焦自动关闭，行为与原生输入法一致
- 系统托盘常驻，设置可视化修改
- 主页时间问候卡片（按上午/中午/下午/晚上自动变化）

## 情绪识别

打字时会判断你当前的情绪并推荐对应的颜文字。比如：

| 你打的字 | 推荐分类 |
|----------|----------|
| 哈哈哈哈哈 | 开心 |
| 今天一点都不开心 | **伤心**（不是开心） |
| 虽然很累但是很开心 | **开心**（取后半句） |
| 为什么？ | 思考 |
| 吃饭了吗 | 不弹（闲聊不打扰） |

实现是一个**约 9000 参数的小神经网络**（纯 Python，无第三方依赖，
权重约 190KB，单次判定 1ms 左右），而不是关键词匹配——因为「不开心」和
「开心」只差一个字，关键词看不懂，网络能整体理解。

它不是"有网络就全信网络"，而是和关键词分工，规则来自实测：

| 情况 | 谁说了算 | 为什么 |
|------|----------|--------|
| 句子里有否定词 | 网络 | 「今天一点都不开心」关键词必然判反 |
| 「我没生气」这类否认 | 都不弹 | 在否认情绪，不是在表达情绪 |
| 句子里有转折词 | 网络（需很确定） | 「本来挺高兴，结果被气到了」后半句才是真情绪 |
| 其它有明确情绪词 | 关键词 | 它零误报，最可靠 |
| 都没命中但像在夸 | 启发式 | 救回「好萌」「太赞了」 |

它还会**边用边学**：你从某个情绪的候选里选了一张，就等于告诉它
"那句话是这个情绪"，它立刻微调一次权重（约 0.3ms），越用越贴合你的
说话方式。学到的权重存在 `%APPDATA%/KaomojiAssistant/emotion_model_user.json`。

### 可以调的地方

在「设置 → 情绪推荐」里：

| 选项 | 说明 |
|------|------|
| 按情绪推荐颜文字 | 总开关。关掉后打字不再自动推荐，热键唤起等照常用 |
| **用 AI 判断情绪** | 关掉后完全走纯算法（关键词表），不加载也不写模型文件 |
| 推荐灵敏度 | 往左更保守（少打扰），往右更容易触发。不同人对"打扰"的容忍度差别很大，这个由你决定 |
| 学习我的用词习惯 | 关掉后不再调整模型，已学到的保持不变 |
| 清除学习记录 | 觉得"越学越偏"时一键回到出厂模型 |

### 开不开 AI 有什么区别

| 你打的字 | 用 AI | 纯算法 |
|----------|-------|--------|
| 今天一点都不开心 | **伤心** ✓ | 开心 ✗（只看到"开心"） |
| 虽然很累但是很开心 | **开心** ✓ | 开心 ✓ |
| 好萌 | **喜欢** ✓ | 不弹 |
| 吃饭了吗 | 不弹 ✓ | 不弹 ✓ |
| 我很开心 | 开心 ✓ | 开心 ✓ |

简单说：**AI 能看懂否定句和口语，纯算法只能认词表里有的词**。

关掉 AI 后的好处是行为完全可预测、不碰任何模型文件；
代价是「今天一点都不开心」会被判成开心。

页面下方会显示当前状态，例如「出厂模型学过 5191 句 · 本次已学习 12 次」
或「当前使用纯算法（关键词匹配），不加载模型、不学习」。

改词表或想重新训练：

```
.venv\Scripts\python.exe tools\train_emotion_model.py
```

训练完跑评测看真实水平（**不要只看训练集准确率**）：

```
.venv\Scripts\python.exe tools\eval_emotion.py
```

历史实验记录在 [docs/emotion_lab_log.md](docs/emotion_lab_log.md)。

## 配置

编辑 `config.json`，或托盘右键「设置」可视化修改（即时生效）：

- `hotkey` 热键 · `theme` 主题 · `opacity` 不透明度 · `acrylic` 亚克力 · `input_method` 输入方式（三选一：`clipboard` 剪贴板粘贴为默认，发 Ctrl+V 不被中文输入法拦截、兼容性最好；`direct` 直接字符投递用 WM_CHAR 直送焦点控件，绕过输入法、无乱码、不污染剪贴板，推荐在中文 Windows 下替代 `type` 使用；`type` 模拟键入在微软拼音等中文输入法下可能产生乱码，仅推荐英文输入模式使用）

## 自定义颜文字

编辑 `data/kaomoji.json`，在对应分类的 `items` 中增删即可：

```json
{ "categories": [ { "name": "开心", "items": ["(｡･ω･｡)", "(◕‿◕)"] } ] }
```

## 编译 EXE（发布版）

把项目打包成 Windows 可执行程序（onedir 模式，无控制台窗口，托盘常驻）：

```bat
.venv\Scripts\activate
pip install -r requirements.txt
python build.py
```

- 产物在 `dist\KaomojiAssistant\`（含 `KaomojiAssistant.exe` 与依赖 DLL、data 资源）。
- 打包时会**自动生成 `app.ico`**（与系统托盘同款的「白底圆角 + 颜文字 (◕‿◕)」图标），作为 exe 文件图标，无需手动准备图片。
- 只读资源 `data/kaomoji.json` 由 `core/runtime.py` 在运行时自动定位（源码态取项目目录，冻结态取 `_internal`），两种形态互不干扰。

## 首次使用

第一次启动会弹出欢迎界面，介绍核心用法并**告知风险**：

- UIA 提权需要管理员权限（会弹 UAC 并以管理员身份重启）；
- 插件以与主程序相同的权限运行（请只安装可信来源的插件）。

需要勾选「我已阅读并了解上述风险」才能继续。这个界面**只出现一次**。

## 自动更新

> ⚠ **仅打包后的 exe 支持**。自动更新需要替换安装目录里的文件，
> 源码运行（`python main.py`）时该功能不可用。

- 启动 30 秒后在后台检查 GitHub Releases，**每 24 小时最多一次**；
- 发现新版本会**静默下载并校验 SHA-256**，不打断你的使用；
- 下载完成后：
  - **关闭程序时自动安装**（最无感，下次启动即是新版）；
  - 或在「关于」页点「立即重启并更新」当场升级；
- 可在设置里关掉自动更新（`auto_update`）。

更新过程：退出程序 → 把旧版改名为 `.old` → 解压新版 → 启动 → 清理备份。
任何一步失败都会**自动回滚**到旧版本。

发布时 `build.py` 会自动生成结构正确的发布包：

```
dist/KaomojiAssistant-v1.2-win64.zip
  └── KaomojiAssistant/
        ├── KaomojiAssistant.exe
        └── _internal/...
```

把这个 zip 上传到 GitHub Release 即可被自动更新识别。

## 开机自启动

- 在「设置 → 系统 → 开机自动启动」中开启。
- 默认通过写入当前用户注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 实现，**无需管理员权限**。
- **开启「UIA 提权」时会自动改用计划任务**（以最高权限运行、登录时触发），
  这样开机后直接具备管理员权限，不必每次弹 UAC 确认。
- 已安装版本的用户配置位于 `%APPDATA%\KaomojiAssistant\`（含 `config.json`、`user_state.json`），重装不丢失。

## UIA 提权

用于让候选栏成为 UIAccess 顶级窗口，能与屏幕键盘等系统级窗口互相覆盖。
这是**正式功能**（不再属于测试功能）。

> ⚠ **仅打包后的 exe 支持**。源码运行（`python main.py`）时该功能被禁用：
> 提权后只能启动 `python.exe` 而不是本程序，开关在设置页显示为不可用并说明原因。

- 在「设置 → 高级 → UIA 提权」开启；
- **不需要手动以管理员身份运行**——开启时会弹 Windows 的 UAC 确认框，
  同意后程序自动以管理员身份重启，再派生 UIAccess 令牌；
- 同时开启「开机自动启动」的话，会创建计划任务，以后开机即为管理员权限，不再弹 UAC；
- 退出程序后恢复普通权限。
