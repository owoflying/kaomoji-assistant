# 情绪识别炼丹记录

每次改模型/数据/特征后，跑一次 `tools/eval_emotion.py` 并在此追加一行。
**只看独立语料与双层协作的数字**，训练集准确率没有意义（会背题）。

## 指标说明

- **独立语料**：`tools/eval_corpus.py`（75 句，不参与训练）
- **双层协作**：`emotion_classifier.detect()` 的实际表现 —— 这是用户感受到的
- **漏判**：应弹没弹（用户觉得功能没用）
- **误报**：不该弹却弹（用户觉得功能很烦）
